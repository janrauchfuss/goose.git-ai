# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through
[GitHub Security Advisories](https://github.com/janrauchfuss/goose.git-ai/security/advisories/new).
You will get a first response within 7 days.

The hook runs as a local shell command with the permissions of the goose session. Reports about
command injection, unsafe handling of the hook payload or path traversal are especially welcome.
